Il Segno sull'Auto — Landing Page

    John 14:6 — "Io sono la via, la verità e la vita. Nessuno viene al Padre se non per mezzo di me."

Una landing page multilingue, gratuita e ospitata su GitHub Pages, accessibile tramite QR code apposto sull'auto.
Descrizione
Questa pagina è stata creata da qualcuno che è morto in terapia intensiva ed è tornato arrabbiato.
Il segno sull'auto è reale. La persona è reale. Tu sei reale. Parliamone.
La pagina presenta il messaggio di Giovanni 14:6 in 14 lingue:
Italiano, Inglese, Spagnolo, Francese, Tedesco, Olandese, Portoghese, Rumeno, Greco, Polacco, Russo, Ebraico, Arabo, Cinese.
Caratteristiche

    Completamente gratuita — nessun costo di hosting, nessun abbonamento
    Multilingue — 14 lingue con switcher rapido
    Design elegante e sobrio — tema scuro con accenti dorati
    Contatore visibile — numero di scansioni del QR code (CountAPI, gratuito)
    Analytics privacy-friendly — GoatCounter (invisibile, no cookie banner)
    Musica di sottofondo opzionale — pulsante flottante per attivare audio soft
    Ottimizzata per mobile — pensata per chi scansiona dal cellulare
    Pulsante di contatto — link mailto per ogni lingua
